# Power BI Dashboard Blueprint

## Goal
Build a 5-page Power BI report that proves product usage -> business outcome mapping.

## Data Source Options
1. Recommended for interview speed: Import CSV extracts generated by project scripts.
2. Recommended for live demo: BigQuery connector (Import mode first, then DirectQuery if needed).

## Required Tables
- `mart_funnel_monthly`
- `mart_cohort_retention`
- `mart_feature_adoption`
- `mart_feature_impact`
- `mart_revenue_bridge_quarterly`
- `mart_account_monthly_state`

## Page 1: Funnel Leakage
Visuals:
- Funnel chart
  - Group: `step_name`
  - Values: `users_at_step`
  - Filter: single `month` (or latest month)
- Matrix/table
  - Columns: `step_name`, `conversion_from_prev`, `dropoff_from_prev`
  - Sort by custom step order

Calculated Column (Power BI):
```DAX
Step Order =
SWITCH(
    'mart_funnel_monthly'[step_name],
    "Signup", 1,
    "First Invoice Created", 2,
    "First Payment Received", 3,
    "App Integration Connected", 4,
    "Plan Upgrade", 5,
    99
)
```

## Page 2: Cohort Retention
Visuals:
- Matrix heatmap
  - Rows: `cohort_month`
  - Columns: `age_month`
  - Values: `retention_rate`
  - Conditional formatting: background color scale (green 100% -> red 0%)
- Card
  - Month-6 average retention

Measure:
```DAX
Month 6 Retention Avg % =
AVERAGEX(
    FILTER('mart_cohort_retention', 'mart_cohort_retention'[age_month] = 6),
    'mart_cohort_retention'[retention_rate]
)
```

Note: Cohorts are based on first payment month (not signup). Month-0 retention should be ~100% since the denominator is paid customers.

## Page 3: Feature Adoption Comparison
Visuals:
- Line chart: adoption_rate by month, color-coded by feature_name
  - Shows bank_feed_sync vs multi_currency vs recurring_invoices side by side
- Clustered bar: adopted_accounts by feature_name for latest month
- Card: overall adoption rate for primary feature (bank_feed_sync)

Measures:
```DAX
Primary Adoption % =
CALCULATE(
    AVERAGE('mart_feature_adoption'[adoption_rate]),
    'mart_feature_adoption'[feature_name] = "bank_feed_sync"
)

Feature Count Avg =
AVERAGE('mart_account_monthly_state'[features_adopted_count])
```

## Page 4: Revenue Bridge (Waterfall)
Visuals:
- Waterfall
  - Category: `bridge_component`
  - Y-axis: `amount`
  - Filter: single `quarter` (latest positive quarter recommended)
  - Components include: New Customers, Plan Upgrade, Feature Adoption Lift, Other/Residual, Contraction, Churn
- Stacked column or table for shares
  - `bridge_component`, `amount`, `share_pct`

Calculated Column (sort order):
```DAX
Bridge Sort =
SWITCH(
    'mart_revenue_bridge_quarterly'[bridge_component],
    "New Customers", 1,
    "Plan Upgrade", 2,
    "Feature Adoption Lift", 3,
    "Other/Residual", 4,
    "Contraction", 5,
    "Churn", 6,
    99
)
```

Then set `bridge_component` -> Sort by column -> `Bridge Sort`.

## Page 5: Feature Impact Matrix
Source table: `mart_feature_impact`

Visuals:
- Clustered bar chart: churn_rate by feature_name, color-coded by segment (adopted vs not_adopted)
  - Shows at a glance: "bank_feed_sync adopters churn X% less than non-adopters"
- Grouped bar chart: avg_mrr by feature_name, split by segment
  - Shows MRR uplift per feature adoption
- Matrix/table: feature_count segment (0, 1, 2, 3 features) with columns:
  - `total_accounts`, `churn_rate`, `contraction_rate`, `avg_mrr`, `total_mrr`
  - Conditional formatting: churn_rate red scale, avg_mrr green scale
- Card: churn rate delta (adopted vs not_adopted) for primary feature

Measures:
```DAX
Adopted Churn Rate =
CALCULATE(
    AVERAGE('mart_feature_impact'[churn_rate]),
    'mart_feature_impact'[segment] = "adopted",
    'mart_feature_impact'[feature_name] = "bank_feed_sync"
)

Non-Adopted Churn Rate =
CALCULATE(
    AVERAGE('mart_feature_impact'[churn_rate]),
    'mart_feature_impact'[segment] = "not_adopted",
    'mart_feature_impact'[feature_name] = "bank_feed_sync"
)

Churn Rate Delta =
[Non-Adopted Churn Rate] - [Adopted Churn Rate]

MRR Uplift Per Feature =
CALCULATE(
    AVERAGE('mart_feature_impact'[avg_mrr]),
    'mart_feature_impact'[segment] = "adopted"
)
-
CALCULATE(
    AVERAGE('mart_feature_impact'[avg_mrr]),
    'mart_feature_impact'[segment] = "not_adopted"
)
```

Key story: "Accounts that adopted bank_feed_sync churn at X% vs Y% for non-adopters. Accounts with 3+ features have Z% avg MRR vs W% for zero-feature accounts."

## Core KPI Cards (Top ribbon on each page)
- Average Adoption %
- Latest Quarter Positive Delta
- Feature Adoption Lift Share % (latest selected quarter)
- Churn Impact (latest quarter)

Measures:
```DAX
Adoption % Avg = AVERAGE('mart_feature_adoption'[adoption_rate])

Positive Delta =
SUMX(
    FILTER('mart_revenue_bridge_quarterly', 'mart_revenue_bridge_quarterly'[amount] > 0),
    'mart_revenue_bridge_quarterly'[amount]
)

Feature Lift Share % =
DIVIDE(
    CALCULATE(
        SUM('mart_revenue_bridge_quarterly'[amount]),
        'mart_revenue_bridge_quarterly'[bridge_component] = "Feature Adoption Lift",
        'mart_revenue_bridge_quarterly'[amount] > 0
    ),
    [Positive Delta]
)

Churn Impact =
CALCULATE(
    SUM('mart_revenue_bridge_quarterly'[amount]),
    'mart_revenue_bridge_quarterly'[bridge_component] = "Churn"
)

Net Revenue Delta =
SUM('mart_revenue_bridge_quarterly'[amount])
```

## Recommended Filter Pane
- `quarter` (single select on Revenue page)
- `month` (date range on Funnel + Adoption trends)
- `cohort_month` (range on Cohort page)
- `feature_name` (multi-select on Adoption page)

## Report Title Suggestion
"Feature Adoption -> Revenue Bridge (Product Analytics)"

## Interview Storyline
1. Funnel page: where activation leakage starts and which step loses the most users.
2. Cohort page: who stays, and whether paid cohorts after feature improvements show better M+6 retention.
3. Feature page: compare adoption rates across features; link multi-feature users to higher retention.
4. Revenue page: full growth decomposition including expansion (new + upgrade + feature lift) and contraction (churn + downgrades). The waterfall tells the complete story.
5. Feature Impact page: the "so what" — adopted vs not-adopted churn rates, MRR uplift per feature, and feature count vs LTV curve. This is where product strategy meets revenue.
